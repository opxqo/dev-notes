# 高端插画海报

> 🏠 [[生图提示词]] > [[图生图]] > [[建筑]]
>
> 相关风格：[[二维矢量插画]] | [[冰箱贴设计]]

```
将参考图中的建筑主体转化为一张高端极简主义建筑插画海报。保留建筑最具识别度的轮廓、结构、材料和比例，去除人群、车辆、水印和杂乱背景，将建筑置于画面中心，以精致建筑插画形式呈现。

背景放置一个巨大加粗的英文单词"[英文大词]"，字体高级，极具设计感，位于建筑背后并被建筑部分遮挡。字体结构需与建筑的轮廓、轴线、曲线、屋檐、网格或立面节奏产生呼应，像是建筑向外延展出的视觉构件。

整体为竖版高端艺术海报，风格类似建筑展览主视觉、奢华杂志封面、博物馆收藏级海报。色彩从建筑本身提取，使用克制的象牙白、暖灰、石材色、香槟金、深灰、砖红、木色或钢蓝，不使用高饱和颜色。

建筑周围加入少量小字说明。用英文描述设计哲学，例如"[设计短语]"，并配合细线、圆点、几何辅助线、轴线和比例线。底部加入建筑名称"[建筑名称]"和城市"[城市，国家]"。整体要求：高级，极简，留白，精致排版，克制配色，中心构图，建筑感强，无杂乱元素。
```
