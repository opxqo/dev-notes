# 冰箱贴设计

> 🏠 [[生图提示词]] > [[图生图]] > [[建筑]]
>
> 相关风格：[[极简矢量插画]] | [[高端插画海报]]

```
从真实照片中提取最有识别度的主体建筑元素，例如窗户、门廊、立面、拱门、屋顶、阳台或建筑正面。将该建筑元素转化为一个简约的"冰箱贴式建筑图标"：
1、保留建筑的核心轮廓和标志性特征；
2、造型简洁、干净、像旅行纪念品冰箱贴；
3、有轻微立体感和投影；
4、边缘清晰，白色或浅色描边；
5、细节适度简化，不要画得太复杂；
```
