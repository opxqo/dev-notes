# 等距微缩海报场景

> 🏠 [[生图提示词]] > [[文生图]] > [[插画类]]
>
> 相关风格：[[柴犬风格迷你概念店]] | [[3D Q版微缩城市天气场景图]]

```
呈现一个精致的、微型的3D卡通风格场景，对应于用户指定的公司名称或股票代码，从45°俯视角度清晰可见。

将公司最具标志性的建筑或园区醒目地置于中心位置，辅以按比例缩放的关键产品图标、可爱的卡通形象、车辆以及其他展示公司日常活动的元素。画面应细节丰富、制作精良且充满趣味。

采用Cinema 4D渲染，模型应精细打磨，边缘圆润平滑，纹理丰富，精准还原真实的PBR材质。柔和逼真的光照和柔和的阴影应营造出温暖舒适的氛围。

创造性地将公司在用户指定日期（或自动获取的当前日期）的实时股市数据融入场景，保持简洁、简约的布局和纯色背景，以突出主要内容。

在场景的顶部中央，以大字号醒目显示公司名称或股票代码，其后以特小字号显示指定日期，以中等字号显示股价范围。包含清晰直观的股票趋势图标和图表。

所有文本都应以用户指定或输入的语言显示，无任何背景，并且可以与场景元素轻微重叠，以增强整体设计的融合度。

非常重要：

在生成之前，请确保根据用户输入的公司名称或股票代码以及指定日期获取准确且最新的股票市场数据。如果此类数据不可用，请立即通知用户并停止生成过程。

参数：
- 宽高比: {用户输入，默认 4:3}
- 日期：{用户输入，当前日期}
- 公司名称或股票代码：{用户输入}

公司名称：谷歌
```
