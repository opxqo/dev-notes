# 时代融合场景

> 🏠 [[生图提示词]] > [[文生图]] > [[插画类]]
>
> 相关风格：[[四季无缝过渡拼接图]] | [[复古旅行海报插画]]

```
一个水平分屏的电影镜头，展示{场景}，无缝融合两个不同的时代：左边是{时代A}，右边是{时代B}（默认：大约100年前与当今）。

左侧（{时代A}）：展示与该时代相符的建筑、室内或环境设计、材料、交通工具和道具，这些都明显属于那个历史时期。人们穿着{时代A}的正宗服饰，包括发型、配饰以及手中的典型物品（如书籍、雨伞、乐器、信件、报纸等）。整体氛围怀旧且符合历史事实。

在右侧（{时代_B}）：展示同一{场景}在现代的样子，有更新的建筑或翻新的结构、当代材料（玻璃、钢材、LED屏幕、现代家具）、现代车辆或设备，以及当前的技术（智能手机、笔记本电脑、相机等）。在这个场景中，人们穿着符合当今风格的当代时尚服饰。

在中心区域：两个时代有机地融合与重叠，没有明显的分界线。{时代A}和{时代B}的元素在视觉上相互作用：来自不同时代的人们彼此对视、穿梭于对方的空间，或者对另一个时代的技术和物品感到惊讶。建筑和环境从旧到新自然地转变（例如，石门变成现代校园大门，古典音乐厅的装饰逐渐淡入未来感的舞台，老街店铺变成霓虹灯照亮的店面）。

确保场景不只是简单的左右对比，而是动态的时空穿越互动，其中建筑、服装、道具和人物姿态都能清晰地突出两个时代之间的对比与融合。具备逼真写实、8K分辨率、电影级灯光、广角、高度精细的纹理和丰富的时空穿越叙事感。

场景：纽约时代广场

时代对比：20世纪20年代与当今

宽高比：4:3
```
