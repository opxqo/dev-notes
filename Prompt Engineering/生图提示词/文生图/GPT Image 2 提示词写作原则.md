# GPT Image 2 提示词写作原则

> 🏠 [[生图提示词]] > [[文生图]]

来源：[CubistAI - GPT Image 2 最佳提示词](https://cubistai.app/zh/blog/gpt-image-2-best-prompts)

## 五条核心原则

### 1. 指定相机和胶片型号
如 "35mm film photography"、"anamorphic lens"、"shot on iPhone" 等表述可在一秒内锁定整体视觉气质，GPT Image 2 对具体相机和胶片的"质感"有很强的直觉。

### 2. 明确写出光线
如机顶硬直闪、窗边柔和漫射光、春日金色光等。光线词对情绪的塑造远超主体词本身，省略则画面平淡。

### 3. 指定画幅和取景
模型同时尊重提示词里的画幅指令和 API 的 size 参数。复杂场景还需描述取景方式，如亲密中景、极低机位仰拍等。

### 4. 用一种基础美学锚定风格
直接说出视觉门类，如"电影感动漫主视觉"、"1960年代旅游海报风格"，往往比十个形容词更有效。

### 5. 加入文化与情境细节
GPT Image 2 对文化梗的理解深度令人惊讶，能用具体专有名词的地方就别用泛泛说法。

## 改造提示词技巧

- **换主体，留光线和镜头：** 魔法在"35mm胶片 + 窗光"组合，换不同主体同样成立
- **换专有名词，留结构：** 换上不同城市的河流、地标和标语就变成其他城市海报
- **换年代，留媒介：** 换一个年代词就能变成不同年代风格
- **跨提示词组合素材：** 把 A 提示词的光线描述搬到 B 提示词上
- **少用否定描述：** GPT Image 2 对"正面指令"的遵循远好于"否定指令"
- **拿不准就写得更长：** 出图平庸时，答案通常是更具体而非更简短

## 常见问题

- **提示词写多长合适？** 从一句话到200字以上段落都能稳定处理
- **支持中文吗？** 完全支持。想让画面出现中文字符时，用中文写整段提示词字形更干净
- **怎么写带文字/排版的提示词？** 用引号写出准确文本，指明位置，描述字体风格
