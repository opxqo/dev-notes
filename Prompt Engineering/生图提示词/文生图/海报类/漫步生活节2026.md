# 漫步生活节 2026

> 🏠 [[生图提示词]] > [[文生图]] > [[海报类]]
>
> 相关风格：[[城市宣传海报]] | [[2026春季波士顿城市海报]]

城市商业活动海报，双吉祥物（粉色大象 + 浅蓝小老鼠）在阳光明媚的商业街上欢快奔跑，营造节庆氛围。

## 为什么有效

典型的商业活动海报提示词结构，分为四个层次：**活动信息**（名称/主题/时间/地点）、**场景设定**（城市/天气/地标）、**主体角色**（双吉祥物+动作）、**文案叠加**（顶部小字/CTA）。中英混合的文案风格适合国内商业场景，吉祥物的毛绒质感和欢快动作传达亲和力。

## 结构模板

| 类别 | 字段 | 说明 |
|------|------|------|
| 活动信息 | CASE_NAME / EVENT_NAME / DATE_RANGE / LOCATION_TEXT | 活动名称、主题、时间、地点 |
| 场景设定 | CITY_OR_DISTRICT / SKY_AND_WEATHER / GROUND_PLANE / LANDMARKS | 城市氛围、天气、地面、地标 |
| 主体角色 | PRIMARY_MASCOT / SECONDARY_MASCOT / MASCOT_ACTION | 主副吉祥物外观+动作 |
| 文案叠加 | TOP_MICRO_TEXT / CTA_TEXT | 顶部小字、行动号召 |
